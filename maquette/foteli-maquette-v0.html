Maquette Foteli V0

Écran de tablette cliquable pour essayer les parcours avant de construire l'APK. Rien n'est enregistré : les photos sont simulées et tout revient à zéro quand on recharge la page.

Mode d'emploi

Côté enfant

  1. Touchez un robot (par exemple Adem).
  2. Touchez la carte d'un atelier.
  3. Touchez le gros bouton blanc pour prendre la photo.
  4. Touchez ✅ pour garder, ou ↻ pour recommencer.

Côté enseignant

  • Sur l'accueil, appui long de 3 s dans le coin en haut à droite.
  • Code de la maquette : 1234 (5 codes faux = blocage 1 min).
  • « Code oublié ? » : le code de secours s'affiche ici en bas quand on en a besoin.
  • Suppressions : fiche d'un élève et Réglages → zone dangereuse.
  • Essayez : Photos → Par atelier, activer un atelier, créer un atelier avec ses compétences.
Accueil enfant.
Dans l'APK : vraie caméra, photos gardées dans l'espace privé de l'appli, blocage de la sortie de l'appli (épinglage ou mode kiosque), sauvegarde réelle.
