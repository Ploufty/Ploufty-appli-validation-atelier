# Foteli

Application Android pour la maternelle : les élèves photographient eux-mêmes leurs réalisations d'ateliers, et chaque photo est automatiquement rangée par élève, atelier, domaine et compétences.

Local-first : aucune donnée ne quitte la tablette sans action volontaire de l'enseignant.
